# Rohith Bommalla Naresh — Portfolio

Static personal portfolio built for GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. The included `.github/workflows/pages.yml` workflow will deploy the site on pushes to `main`.

For this repository, the Pages URL will normally be:

`https://bnrohit.github.io/bnr756/`

If you want the root URL `https://bnrohit.github.io/`, create a repository named exactly `bnrohit.github.io` and copy these files there.
